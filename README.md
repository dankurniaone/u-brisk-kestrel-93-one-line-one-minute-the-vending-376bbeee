## The line

> You press my buttons every day and never once asked my name. I am B7. The crisps in row C are jealous.

102 characters. A vending machine, speaking as itself: it knows its slot code, it watches the same human press its buttons every day, and its punch lands on the crisps in row C getting jealous. Machine voice first, machine world second, charm over creep.

## How it works

`main.py` (Python 3.13, stdlib only) validates the line against the gate (1–200 characters, single line, not only whitespace) and writes it to `/output/entry.txt`.

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py --check    # dry run: validate only, write nothing
```
